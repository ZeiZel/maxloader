Данные не собираются, не хранятся и не передаются третьим лицам.

Расширение работает только на web.max.ru. Оно читает DOM выбранных сообщений, чтобы найти вложения,
и перехватывает ссылку, которую сам сайт формирует для скачивания файла. Ссылка передаётся только
служебному процессу самого расширения и используется единственный раз — чтобы сохранить файл через
стандартный механизм загрузок Chrome. Никуда за пределы браузера ссылка не уходит.

Разрешение "downloads" запрашивается исключительно для сохранения файлов, которые пользователь сам
выбрал в переписке. Собственных сетевых запросов расширение не выполняет.
